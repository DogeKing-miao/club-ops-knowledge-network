## 一个关键说明（为什么和手册里的语句不完全一样）
这个版本的 Neo4j Browser 在**一次提交多条语句**时，结果卡片会折叠成「摘要行」，表格看不到。
所以「先…再…」的两段对照，我合并成**一条语句**（用 `COUNT { }` 子查询 / 列表推导），保证「语句 + 结果表」同框。
Cypher 语义与手册完全一致，只是写法合并了。

```cypher
// 前

RETURN s.name AS 学生, 已加入社团, 社团数,
```

```cypher
// 执行
```

**08-动作2前.png / 09-动作2后.png（F12 郑亦航报名秋季观星夜）**

```cypher
RETURN a.name AS 活动, a.capacity AS 总名额, a.remaining AS 剩余名额, a.status AS 状态,
       COUNT { (s0:Student)-[:SIGNED_UP]->(a) } AS 已报名人数;
```

```cypher

MATCH (s:Student {studentId:'S008'}), (a:Activity {activityId:'A01'}) WHERE a.remaining > 0
MERGE (s)-[r:SIGNED_UP]->(a)
```
