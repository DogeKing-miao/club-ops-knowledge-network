## 二、运行环境

| 项目 | 要求 | 说明 |

| 图数据库 | **Neo4j 5.x**（在线沙箱即可） | 脚本用 `CREATE CONSTRAINT ... IF NOT EXISTS`、`COUNT { }` 子查询、`date()` / `datetime()`，均为 Neo4j 5 语法 |
| 数据库访问方式 | Neo4j Browser（浏览器网页）或 <https://browser.neo4j.io> | 无需本地安装任何东西 |

## 三、Neo4j 沙箱导入与查询步骤

> 全部操作在浏览器里完成，约 5 分钟建好整张知识网络。
> 详细到「每一步应该看到什么」的版本见 `docs\Neo4j 查询操作手册.docx`。

### 第 1 步 · 开一个沙箱

1. 打开 <https://sandbox.neo4j.com>
2. 用 Google 账号或邮箱登录（免费）
3. 点 **Create instance** → 选 **Blank Sandbox**（不要选带数据集的）→ 起个名字
4. 等状态变成 **Running** → 点 **Open**，进入 Neo4j Browser

### 第 2 步 · 导入数据（两种方式，任选一种）

**方式 A（首选，一次建好整张网）**

1. 用记事本 / VS Code 打开 `cypher\00_一键运行.cypher`
2. **全选 → 复制**
3. 粘进 Neo4j Browser 左上角那个显示 `neo4j$` 的输入框
4. 按 **Ctrl + Enter**

这个脚本一共 **63 条可执行语句**：11 个唯一约束 + 35 个实体 + 属性补全 + 74 条关系 + 自检。
全部用 `MERGE` + 唯一约束写的，**重复执行不会产生重复数据**。

> 提示 `An equivalent constraint already exists` 属**正常**，说明约束之前建过，继续跑即可。
> 如果一次粘贴页面卡住：按脚本里标注的 **4 段**（约束 / 实体 / 关系 / 自检）分开跑，每段以 `;` 结尾。

**方式 B（分段跑）**

先跑 `cypher\02_seed_entities.cypher`（只建 35 个点），再跑 `cypher\03_seed_relations.cypher`（属性补全 + 74 条关系）。

### 第 3 步 · 自检（数字对不上就别往下做）

在输入框里逐条粘贴、`Ctrl + Enter`：

```cypher
MATCH (n) RETURN count(n) AS 实体总数;
```

应看到 **35**（赛题要求不少于 20 个，为其 1.75 倍）。

```cypher
MATCH ()-[r]->() RETURN count(r) AS 关系总数;
```

应看到 **74**。

```cypher
MATCH (n) RETURN labels(n)[0] AS 类型, count(*) AS 数量 ORDER BY 数量 DESC;
```

应看到 11 行：学生 8、活动 4、兴趣标签 4、社团 4、部门 3、场地 3、老师 2、招新 2、通知 2、获奖 2、学期 1。

### 第 4 步 · 看图谱（可视化）

```cypher
MATCH (n)-[r]->(m) RETURN n, r, m LIMIT 150;
```

跑完后点结果卡片上的 **Graph** 标签 → 一片圆点和连线。
想显示中文名：点 Graph 视图左下角的小图标，把**节点标题属性设为 `name`**。

### 第 5 步 · 跑查询（9 个场景）

打开 `cypher\04_queries.cypher`，**一个查询整段复制**粘贴运行（每段以 `;` 结尾）。
每条查询上方都写了对应的功能编号与**预期结果**，跑出来和注释一致就说明数据与脚本都对。

想「照着一步步贴」：用 `cypher\06_演练步骤（照着一步步贴）.cypher`，按 `▶` 标记一步一段地复制。

### 第 6 步 · 演示业务动作（前后变化）

打开 `cypher\05_actions.cypher`，每个动作按 **执行前 → 执行 → 执行后** 跑三次：

1. 跑「执行前」→ 截图
2. 跑「执行」→ 观察提示（`Create 1 relationship` / `Set N properties`）
3. 跑「执行后」→ 截图

| 动作 | 执行前 | 执行后 |
|---|---|---|
| 动作一 · F11 学生加入社团 | 李思远 社团数 0；星野天文社在册 3 人 | 多一条 `MEMBER_OF`；在册 4 人 |
| 动作二 · F12 学生报名活动（含名额校验） | 秋季观星夜 剩余名额 36、报名 4 人 | 剩余名额 35、报名 5 人 |
| 动作三 · F14 成员退出（改状态不删关系） | 王梓涵 · 拾光摄影社 · 在册（在册 3 / 已退出 0） | 状态改为「已退出」（在册 2 / 已退出 1），**关系仍在** |

每个动作末尾都附了**重置语句**，想再演一遍就跑一下，能回到初始状态。
（`cypher\07_重置与排错.cypher` 里有把整库拉回基线 35 / 74 的完整重置语句。）

> **注意**：跑完动作后关系总数会变成 **76**（动作一 +1 条 `MEMBER_OF`、动作二 +1 条 `SIGNED_UP`），
> 这是正常的。关系基线是 **74**（补 C04 之前是 73）。

### 第 7 步 · 打开离线可视化原型（不联网）

双击 `demo\知识网络图谱（离线中文版）.html` → 浏览器直接打开，不联网、无外部依赖。

页面里能做的事：

- **业务动作（能改）** —— 左侧三个按钮：**学生加入社团 / 学生报名活动 / 成员退出社团**。点一下**真的改动图上的数据**：顶部「关系」计数会变红、图上多出一条边、右侧给出「执行前 → 执行后」对比；点「重置回初始状态」一键复原
  - ⚠️ 只改**本页面内存**，不写回 Neo4j，刷新即复原（演示时不怕点乱）。真实写入见 `cypher\05_actions.cypher`
- **9 个查询场景** —— 底部点 `F5` / `F6` / `F7` / `F8` / `F9` / `F10` / `F17` / `F32` / `F33`：**命中的子图会高亮、其余变淡**，右侧同时给出该场景的**说明与查询结果表**（结果由图数据现算，没有写死）
- **节点详情** —— 点任意节点，右侧显示它的**中文属性**与**直接关系**（关系名与属性名都做了中英映射）
- **图谱浏览** —— 滚轮缩放、空白处拖动平移、**拖节点可挪位置**；左侧图例可**按类型隐藏/显示**；搜索框支持按姓名 / 社团 / 活动 / 编号定位
- **深浅色切换** —— 右上角一键切换，适合投影或截图

数据与 `data\entities.csv`、`cypher\03_seed_relations.cypher` 完全一致（**35 实体 / 74 关系 / 18 种关系类型**）；场景与 Cypher 对应 `cypher\04_queries.cypher`。业务动作见 `cypher\05_actions.cypher`（在 Neo4j 里执行，不在本页面上）。

### 沙箱过期了怎么办

沙箱有效期约 **3 天**。过期后：新建一个实例 → 重跑 `cypher\00_一键运行.cypher` 即可。
**数据不会丢**，因为数据全部在脚本里，不依赖手工录入。

## 八、常见问题（排错）

| 现象 | 原因 / 怎么办 |
|---|---|
| `An equivalent constraint already exists` | 正常，说明约束已建过，继续跑下一段 |
| 一次粘贴太多、页面卡住 | 按 `00_一键运行.cypher` 里的 4 段分开跑；每段最后一句是 `;` |
| 查询结果为空 | 先跑 `MATCH (n) RETURN count(n);` 确认是 35；不是就新建一个空白沙箱、重跑第 2 段 |
| 沙箱显示 Expired | 沙箱约 3 天过期：新建实例，重跑 `00_一键运行.cypher` 即可（数据都在脚本里，不会丢） |
| 关系数显示 76 而不是 74 | 正常：3 个动作新增了 2 条关系（`MEMBER_OF` +1、`SIGNED_UP` +1）；74 是动作前的基线（补 C04 之前是 73） |
| 中文列名显示异常 | 刷新页面重跑；或把 `AS 别名` 换成英文 |
| Graph 视图看不到中文名 | 点 Graph 视图左下角小图标，标题属性选 `name` |
| `Too many failed authentication requests` | 密码连错多次被限流：等 2–3 分钟，或重新进沙箱页面 |
| 想要的图形界面 | 除了 Neo4j Browser，可用 <https://browser.neo4j.io> 连同一个实例 |

更完整的排错对照表见 `docs\Neo4j 查询操作手册.docx` 第四部分。
