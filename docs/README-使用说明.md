# 社团运营知识网络 · 使用说明

> 考题六《本体网络：为校园构建一张知识网络》技术向交付物
> 场景：**校园社团运营**（招新、活动、场地、成员、获奖）
> 一句话：把社团、学生、活动、场地之间的关系放进图数据库，做到**能看、能查、能算、能改**。

---

## 一、30 秒跑起来（Neo4j 在线沙箱，免费免安装）

1. 打开 <https://sandbox.neo4j.com>，用 Google 账号或邮箱登录
2. 点 **Create instance** → 选 **Blank Sandbox** → 起个名字 → 等状态变成 **Running** → 点 **Open**
3. 打开本目录的 **`00_一键运行.cypher`**，**整段复制**，粘贴进 Neo4j Browser 的输入框，按 **Ctrl + Enter**
4. 跑完自检，应该看到：

```cypher
MATCH (n) RETURN count(n);            // 实体总数：35
MATCH ()-[r]->() RETURN count(r);     // 关系总数：74
```

> 如果一次粘贴卡住，就按 `00_一键运行.cypher` 里标注的 **4 段**分开跑（约束 / 实体 / 关系 / 自检），每段以 `;` 结尾。
> 脚本用 `MERGE` + 唯一约束写，**重复执行不会产生重复数据**。
> 提示 `An equivalent constraint already exists` 属正常，说明之前跑过。

## 四、怎么演示（建议顺序，约 8 分钟）

**① 看（F1–F4）**：跑下面这句，点结果上方的 **Graph** 标签，双击节点看属性

```cypher
MATCH (n)-[r]->(m) RETURN n, r, m LIMIT 150;
```

**② 查（F5–F7、F10）**：`04_queries.cypher` 第 1、2、3、6 段

**③ 算（F8、F9、F33）**——这三条最能打，务必演示：
- **F8 场地冲突检测**：检出「东区操场 2025-10-18 秋季观星夜 与 校园人像外拍 撞车」
- **F9 招新转化**：列出「李思远、周雨桐 报名了但还没正式入社」
- **F33 报名者筛选与匹配**：按标签算匹配度，李思远命中「天文观测」排第一 —— 这条走的是「报名→招新→社团→标签→学生」的关系链，**表格做不出来**

**④ 改（F11、F12、F14）**：`05_actions.cypher`，每个动作先跑「执行前」，再跑「执行」，最后跑「执行后」，三张截图就是赛题要求的「动作执行前后的变化」

## 六、常见问题

| 现象 | 原因 / 怎么办 |
|---|---|
| `An equivalent constraint already exists` | 正常，说明约束已建过，继续跑下一段 |
| 一次粘贴太多、页面卡住 | 按 4 段分开跑；每段最后一句是 `;` |
| 沙箱显示 Expired | 沙箱约 3 天过期：新建实例，重跑 `00_一键运行.cypher` 即可（数据都在脚本里，不会丢） |
| 查询结果为空 | 先跑 `MATCH (n) RETURN count(n);` 确认是 35；不是就新建空白沙箱重跑 `00_一键运行.cypher` |
| 中文列名显示异常 | 刷新页面重跑；或把 `AS 别名` 换成英文 |
| 想要的图形界面 | 除了 Neo4j Browser，可用 <https://browser.neo4j.io> 连同一个实例 |
